# GROE Design System

## Product character

A modern lifestyle-planning product combining editorial clarity, the satisfaction of arranging a building game and the warmth of an urban gardening brand. It avoids enterprise-dashboard density, monochromatic green, glassmorphism and mascot clutter.

## Tokens

- Canvas: warm mineral off-white `#f7f3e9`
- Text: deep near-black olive `#17251f`
- GROE green: `#214e3b`
- Energy accent: citrus `#f1c84c` and tangerine `#e8793e`
- Secondary differentiation: lilac `#b9a7d8`, sky and coral
- Soil and spatial elements: muted earth tones
- Warning: reserved red `#b74435`

## Interaction hierarchy

Each planner screen follows: clear objective → visual input → immediate feedback → short explanation → one obvious next action.

The result map is the largest visual element. Plant details remain in a separate panel or mobile flow. Plan cards have shared structure but different accent, proposition, crop preview, harvest rhythm and trade-off.

## Accessibility

- High-contrast primary controls.
- Visible keyboard focus.
- Large mobile touch targets.
- Reduced-motion media query.
- Semantic buttons, labels, dialog and SVG roles.
- Plant labels are available through list synchronization and SVG titles.
